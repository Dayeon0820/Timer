# 🎯 공부 집중 타이머

웹캠으로 **졸음**과 **딴짓**을 감지해서, 집중이 깨지면 뽀모도로 타이머를 자동으로 멈춰 주는 웹사이트입니다.
서버나 외부 API 없이 **브라우저 안에서만** 동작하며, 웹캠 영상은 기기 밖으로 전송되거나 저장되지 않습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| ⏱ 뽀모도로 타이머 | 기본 25분 집중 / 5분 휴식. 집중이 끝나면 휴식이 자동으로 시작되고, 설정에서 시간 변경 가능 |
| 😴 졸음 감지 | 양쪽 눈 감김 점수가 0.5 이상인 상태가 2초 이상 지속 |
| 👀 딴짓 감지 | 고개를 좌우로 30° 이상 돌리거나 아래로 25° 이상 숙인 상태가 3초 이상 지속 |
| 🚶 자리 비움 | 얼굴이 5초 이상 검출되지 않음 |
| ⏸ 자동 일시정지 / 재개 | 집중이 깨지면 타이머 정지 + 화면 경고. 다시 정면을 보면 자동 재개 |
| ⏰ 졸음 단계별 대응 | 1단계 화면 깜빡임 → 2단계 경고음 → 3단계 "일어나서 스트레칭" 미션. 계속 졸수록 점점 강하게 깨움 |
| 🎯 정면 맞추기 | 3초 동안 화면을 바라보면 그 자세를 "정면"으로 기억 (기술 용어로는 캘리브레이션) |
| 📊 기록 | 날짜별 집중 시간, 뽀모도로 횟수, 졸음/딴짓/자리비움 횟수를 저장하고 오늘/최근 7일 통계와 차트로 표시 |
| 🕒 시간대별 분석 | 최근 30일 기록을 0~23시로 모아 "나는 오후 3시에 제일 많이 졸아요" 같은 분석과 시간대별 그래프 표시 |
| 🛠 디버그 표시 | 웹캠 미리보기 위에 눈 감김 점수, 고개 각도, 지속 시간을 실시간 표시 |
| ⚙️ 설정 | 타이머 시간, 모든 감지 기준값(임계값·지속 시간), 경고음 on/off |

모든 기준값은 설정 화면에서 바꿀 수 있습니다.

## 사용 기술

- **Vite + React** (JavaScript): 정적 사이트로 빌드
- **[@mediapipe/tasks-vision](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js)의 `FaceLandmarker`**: 얼굴 랜드마크, 블렌드셰이프, 얼굴 변환 행렬
  - 모델 `public/models/face_landmarker.task`, WASM 런타임 `public/wasm/`을 **로컬에서** 불러옴 (CDN 사용 안 함)
  - `runningMode: "VIDEO"`, `delegate: "GPU"` (GPU를 못 쓰는 환경이면 자동으로 CPU 사용)
- **Web Audio API**: 경고음과 알림음을 코드로 직접 생성 (음원 파일 없음)
- **localStorage**: 설정, 정면 기준값, 세션 기록(시간대별 포함) 저장
- **SVG**: 차트 라이브러리 없이 막대 차트와 마스코트를 직접 그림
- **lucide-react** (아이콘), **Pretendard** (글꼴): npm 패키지로 설치해 빌드에 포함 (외부 CDN 사용 안 함)

## 디자인 시스템

세이지 그린 + 아이보리 + 딥그린 조합의 차분한 라이트 테마입니다. 색이나 크기를 컴포넌트에 직접 쓰지 않고 3단계로 나눴습니다.

| 단계 | 위치 | 내용 |
| --- | --- | --- |
| ① 디자인 토큰 | `src/styles/tokens.css` | 원시 팔레트(`--sage-50`~`--sage-900` 등) → 의미 토큰(`--color-primary`, `--color-surface`, `--color-warn` …), 글꼴 크기, 간격(4px 단위), 모서리, 그림자, 모션 |
| ② UI 컴포넌트 | `src/components/ui/` + `src/styles/components.css` | `Button`, `Card`, `ProgressRing`, `Mascot`, `Metric`/`MiniBars`, `TabNav`, `SliderField`/`SwitchField`/`Stepper`, `Chip`/`StatusDot`/`Modal`/`Toast`/`Insight`, `Segmented` |
| ③ 화면 | `src/components/*.jsx` + `src/styles/layout.css` | ②의 컴포넌트만 조합해서 배치 |

- **색을 바꾸려면** `tokens.css`의 의미 토큰만 수정하면 모든 화면에 반영됩니다.
- **마스코트 "새싹떡"**: 상태에 따라 표정이 바뀝니다. 집중(happy), 졸음(sleepy), 딴짓(surprised), 자리비움(worried), 휴식(rest).
- **반응형**: 720px 이하에서는 상단 헤더 대신 화면 제목과 하단 탭바를 쓰고, 타이머 버튼이 아이콘형으로 바뀝니다.
- **뷰포트 맞춤 (높이 기준 반응형)**: 콘텐츠가 화면 경계에서 어중간하게 잘리지 않도록 설계했습니다. (`layout.css` 끝의 "뷰포트 맞춤 레이아웃")
  - 데스크톱/태블릿: 타이머 화면 전체가 스크롤 없이 `100dvh` 안에 들어갑니다. 링 크기는 `화면 높이 − 나머지 요소 높이`로 계산하고, 카메라 화면은 높이가 모자랄 때만 줄어듭니다. 낮은 노트북 화면(≤820px)에서는 보조 문구를 숨기고 지표를 줄입니다.
  - 모바일: "한 화면 = 한 섹션"으로 나눴습니다. 첫 화면에는 타이머가, 두 번째 화면에는 카메라와 지표(3칸 요약)가 딱 맞게 들어가고, 스크롤은 섹션 경계에서 부드럽게 멈춥니다(scroll-snap). 첫 화면의 카메라 상태 칩을 누르면 두 번째 화면으로 이동합니다.
  - 확인한 화면 크기: 1920×1080, 1440×900, 1366×768, 1280×720, 1024×768, 390×844, 375×667, 360×740

## 감지 원리

매 비디오 프레임마다 `FaceLandmarker.detectForVideo()`를 실행하고 그 결과로 상태를 판정합니다.
(`src/hooks/useFocusDetector.js`)

### 1. 졸음: 블렌드셰이프(eyeBlink)
`outputFaceBlendshapes: true`를 켜면 표정 계수 52개가 0~1 점수로 나옵니다.
그중 `eyeBlinkLeft`, `eyeBlinkRight`가 **둘 다** 임계값(0.5) 이상이면 "눈 감음"으로 보고,
이 상태가 시작된 시각을 기록합니다. 감은 상태가 2초 넘게 이어지면 **졸음**입니다.
보통 눈 깜빡임은 0.1~0.4초라서 졸음으로 잡히지 않습니다.

### 2. 딴짓: 얼굴 변환 행렬 → 고개 각도
`outputFacialTransformationMatrixes: true`를 켜면 기준 얼굴 모델에서 현재 얼굴까지의 4×4 변환 행렬이 나옵니다.
왼쪽 위 3×3 회전 행렬을 `R = Ry(yaw) · Rx(pitch) · Rz(roll)`로 분해합니다. (`src/lib/headPose.js`)

```
pitch = asin(-R[1][2])          // 위아래 (양수 = 고개 숙임)
yaw   = atan2(R[0][2], R[2][2]) // 좌우
roll  = atan2(R[1][0], R[1][1]) // 기울기
```

여기서 "정면 맞추기"로 저장한 기준 각도를 빼면 "평소 자세에서 얼마나 벗어났는지"가 됩니다.
`|yaw| ≥ 30°` 또는 `pitch ≥ 25°`(아래쪽만)인 상태가 3초 넘게 이어지면 **딴짓**입니다.

> 카메라 위치에 따라 위/아래 방향이 반대로 잡힐 수 있습니다. 그럴 때는 설정에서 "위/아래 방향 반전"을 켜세요.

### 3. 자리 비움
마지막으로 얼굴이 검출된 시각을 기록해 두고, 5초 넘게 얼굴이 없으면 **자리 비움**입니다.
5초가 안 되게 잠깐 얼굴을 놓친 경우에는 직전 상태를 유지해서 상태가 깜빡이지 않게 했습니다.

### 4. 상태 우선순위와 자동 재개
`자리 비움 > 졸음 > 딴짓 > 집중` 순서로 판정합니다. 조건이 풀리는 즉시(눈을 뜨거나 정면을 보면) **집중** 상태로 돌아오고,
타이머도 자동으로 다시 흐릅니다. 집중이 깨진 동안에는 5초마다 경고음이 반복됩니다.

### 5. 정면 맞추기 (캘리브레이션)
버튼을 누르면 3초 동안 들어온 프레임의 yaw/pitch를 모아 평균을 내고, 이를 기준값으로 localStorage에 저장합니다.
노트북 카메라가 화면 아래나 옆에 있어도 "내가 화면을 보는 자세"를 0°로 맞출 수 있습니다.

### 6. 졸음 단계별 대응 (`src/hooks/useDrowsyEscalation.js`)
계속 졸수록 점점 강하게 깨웁니다.

| 단계 | 언제 | 대응 |
| --- | --- | --- |
| 1 | 졸음이 감지되면 바로 | 화면 깜빡임 (소리 없음) |
| 2 | 4초 더 졸거나, 10분 안에 두 번째 졸음 | 경고음 반복 |
| 3 | 10초 더 졸거나, 10분 안에 세 번째 졸음 | 스트레칭 미션 (미션을 끄면 더 강한 알람) |

**스트레칭 미션** (`src/components/StretchMission.jsx`)은 카메라로 실제 동작을 확인합니다.
① 고개를 한쪽으로 25° 이상 → ② 반대쪽으로 25° 이상 → ③ 일어나서 카메라 밖으로 2초 → ④ 다시 앉아 정면 보기.
미션을 마칠 때까지 타이머는 멈춰 있고, 미션 중의 고개 돌림·자리 비움은 딴짓으로 세지 않습니다.
카메라 인식이 잘 안 되는 경우를 위해 30초 뒤에는 "직접 완료" 버튼이 나타납니다.

### 7. 시간대별 집중 분석 (`src/lib/hourlyAnalysis.js`)
기록을 저장할 때마다 현재 시각(0~23시) 칸에도 함께 쌓습니다.
- **집중도** = 집중한 시간 ÷ (집중한 시간 + 집중이 깨져 타이머가 멈춰 있던 시간)
- 최근 30일을 시간대별로 합쳐서 **집중이 가장 잘 되는 시간**(10분 이상 기록된 시간대 중 집중도 최고), **가장 많이 조는 시간**, **딴짓이 가장 많은 시간**을 찾아 문장으로 보여줍니다.
- 그래프는 집중 시간 / 집중도 / 졸음 / 딴짓 중에서 골라 볼 수 있습니다.

### 성능
- 같은 비디오 프레임은 다시 분석하지 않습니다(`video.currentTime` 비교).
- 디버그 수치는 0.1초 간격으로만 화면에 반영하고, 상태는 바뀔 때만 React state를 갱신해서 불필요한 리렌더를 줄였습니다.

```
│  ├─ lib/
│  │  ├─ headPose.js                # 변환 행렬 → yaw/pitch/roll
│  │  ├─ alarm.js                   # Web Audio 경고음
│  │  ├─ storage.js                 # 날짜별·시간대별 기록 저장
│  │  ├─ hourlyAnalysis.js          # 시간대별 집계 + 분석 문장
│  │  └─ defaults.js                # 기본 설정값, 상태 라벨
│  ├─ styles/                       # tokens → base → components → layout
│  └─ components/                   # ui/ (디자인 시스템) + 화면 (타이머, 카메라 패널, 지표, 기록, 설정, 오버레이)
└─ .github/workflows/deploy.yml     # GitHub Pages 자동 배포
```

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
npm install     # 의존성 설치 + MediaPipe WASM 을 public/wasm 으로 복사
npm run dev     # 개발 서버 → http://localhost:5173
```

> 웹캠은 `localhost` 또는 **HTTPS** 주소에서만 켤 수 있습니다. 같은 와이파이의 휴대폰에서 `http://192.168.x.x`로 접속하면 카메라가 동작하지 않습니다.

빌드 결과 미리보기:

```bash
npm run build   # dist/ 폴더에 정적 파일 생성
npm run preview
```

## 배포 방법

`vite.config.js`에 `base: './'`를 설정해 두어서 어느 경로에 올려도 동작합니다.

### GitHub Pages (자동)
1. GitHub에 저장소를 만들고 코드를 `main` 브랜치에 push 합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. push 할 때마다 `.github/workflows/deploy.yml`이 빌드해서 `https://<아이디>.github.io/<저장소명>/`에 배포합니다.

### Vercel
1. [vercel.com](https://vercel.com)에서 GitHub 저장소를 Import 합니다.
2. Framework Preset은 **Vite**로 자동 인식됩니다. (Build: `npm run build`, Output: `dist`)
3. Deploy를 누르면 끝입니다. Vercel도 `npm install`을 실행하므로 WASM 파일이 자동으로 준비됩니다.

## 개인정보

- 웹캠 영상은 브라우저 메모리 안에서만 분석되고 **어디로도 전송되거나 저장되지 않습니다.**
- 모델과 WASM도 사이트와 같은 주소에서 불러오므로 외부 서버와 통신하지 않습니다.
- 기록과 설정은 이 브라우저의 localStorage에만 저장되며, 기록 화면에서 전부 삭제할 수 있습니다.

## 한계

- 어두운 곳, 역광, 안경 반사가 심하면 눈 감김 점수가 부정확할 수 있습니다. 디버그 표시로 수치를 확인하고 설정에서 임계값을 조절하세요.
- 고개를 많이 숙이면 눈이 감긴 것처럼 보여 졸음으로 판정될 수 있습니다.
- 브라우저 탭이 백그라운드로 가면 브라우저가 화면 갱신을 멈추기 때문에 감지도 멈춥니다. 타이머 시간 계산은 계속됩니다.
